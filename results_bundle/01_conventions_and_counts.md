# 01: Conventions and gate counts

## The gate set: two conventions in use

| | Convention **A** (signed 𝒟) | Convention **B** (unsigned) |
|---|---|---|
| Diagonal gates | diag(±ζ^a, ±ζ^b, ±ζ^c), ζ = e^{2πi/9} | diag(ζ^a, ζ^b, ζ^c) |
| R = diag(1,1,−1) | **in the gate set, charged** | treated as free (draft eq. (37)), though it is not Clifford |
| Used by | Kalra et al. 2311.08696; Evra–Parzanchevski 2401.16120; **our code** | the draft's prose (l.232, l.590) |

- **The draft is internally inconsistent.** Its syllable form and the EP generation theorem it cites need the signed set (A).
- **Exact synthesis needs R.** With the reducer restricted to no-R prefixes, 0/10 matrices decompose (`nick_test/no_r_test.py`).
- **R is not a Clifford, and is not even in the Clifford hierarchy.** So counting it as free (B) understates the cost. An exhaustive search found no R among products of ≤6 unsigned syllables, so R is very likely not in the unsigned group either. See `paper_prep/convention_memo.md`.

## Gate classes

| Class | Definition | Clifford-hierarchy level | Per-phase charge N_φ | Fault-tolerant cost |
|---|---|---|---|---|
| Clifford diagonal | all exponents ≡ 0 (mod 3) | 2 | 0 | 0 |
| **T-type** | non-Clifford, a+b+c ≡ 0 (mod 3) = T or T⁻¹ up to Clifford | 3 | **2** (always exactly 2 phases) | **1 T** |
| **Level-4** | a+b+c ≢ 0 (mod 3) = single-position phase up to Clifford | 4 | **1** (always exactly 1 phase) | **7 T** + clean ancilla |
| **R** | diag(1,1,−1) (also: a residual monomial with mixed signs) | none | 1 under A, 0 under B | **7 T** + clean ancilla |

T = diag(1, ζ₉, ζ₉⁸) is the qutrit T gate (Howard–Vala, Campbell–Anwar–Browne "M"); it is distillable by qutrit Reed–Muller codes.

## Three cost units

- **N_φ (the historical "N_D")**: one per ζ₉ phase with 3∤a, plus one per R under A. This charges each T as 2. It is the unit in which C+D and C+R tie.
- **ops**: one per non-Clifford operation (T-type, level-4 or R).
- **T-cost** = n_T + 7·n_4 + 7·n_R. These are T magic states on a qutrit T-factory machine, using the 7-T gadgets (`03`). This is the physically meaningful unit, and it is the same under A and B.

## What this means for the convention decision
- **The choice changes the headline gate count:** 5.16 (A) vs 4.82 (B) per log₃. Under B, C+D appears to beat C+R Householder and to sit below the 4.90 covering bound. That is an artefact of not charging a non-Clifford gate.
- **It does not change the fault-tolerant cost:** 227 T at 10⁻¹⁰ either way, because each R is a 7-T gadget.
- **Recommendation (from `paper_prep/convention_memo.md`):**
  - use convention A;
  - report the per-class counts (n_T, n_4, n_R) as the primary data and T-cost as the headline;
  - keep N_φ only for comparison with the literature.
